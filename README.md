# Денис Кривошапко — резюме

Статическая адаптивная страница и PDF для работодателей. Внешние шрифты, аналитика и JavaScript не используются.

Для GitHub Pages: в Settings → Pages выбрать Deploy from a branch → main → / (root). При обновлении ветки main сайт публикуется автоматически.

Файлы: index.html, assets/ и Denis_Krivoshapko_CV.pdf. Для обновления PDF заменить файл с тем же именем.
